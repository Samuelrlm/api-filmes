API Filmes

Cadastre, liste, consulte, atualize e exclua filmes. Cada rota abaixo tem exemplo em cURL, fetch e axios.

Base URL http://localhost:5404

Como executar

  1. Instale as dependências com npm install.
  2. Crie o arquivo .env na raiz:
URL_DATABASE=postgresql://usuario:senha@localhost:5432/nome_do_banco

A tabela filmes precisa ter id, titulo, genero, ano, minutos, nota, sinopse e banner. O id é gerado pelo banco.

Desenvolvimento: npm run dev. Produção: npm start. Esta página fica em /docs.

Para os exemplos com axios: npm install axios.

Convenções

  • As rotas de filme ficam em /filmes.
  • POST e PUT recebem JSON. O fetch precisa do header Content-Type: application/json. O axios define esse header quando o corpo é um objeto.
  • Sucesso volta em JSON. Erro volta em texto puro.
  • No fetch, leia o erro com text(). No axios, o texto fica em error.response.data.
  • Não há autenticação. O CORS aceita qualquer origem.
  • O id vai na URL. Ele não entra no corpo.

Campos do filme

Campos aceitos no cadastro e na atualização
Campo Obrigatório Regra
titulo sim texto com no máximo 150 caracteres
genero sim texto com no máximo 50 caracteres
ano sim número. O valor 0 é recusado
minutos sim número. O valor 0 é recusado
nota sim valor preenchido
sinopse sim texto
banner sim URL ou texto do pôster
id não gerado pelo banco

O tipo exato de nota e dos demais campos segue o que o PostgreSQL devolve.

Rotas

GET

/filmes

Devolve todos os filmes cadastrados. Sem registros, a lista vem vazia.

curl http://localhost:5404/filmes
const resposta = await fetch("http://localhost:5404/filmes")

if (!resposta.ok) {
  console.log(resposta.status, await resposta.text())
} else {
  const filmes = await resposta.json()
  console.log(filmes)
}
import axios from "axios"

try {
  const { data } = await axios.get("http://localhost:5404/filmes")
  console.log(data)
} catch (error) {
  console.log(error.response.status, error.response.data)
}

  • 200 Lista de filmes, ou [] quando não há registros.
  • 400 Falha ao consultar o banco: Erro ao buscar filmes
GET

/filmes/:id

Devolve um filme pelo identificador.

curl http://localhost:5404/filmes/1
const resposta = await fetch("http://localhost:5404/filmes/1")
const texto = await resposta.text()
const filme = texto ? JSON.parse(texto) : null

console.log(resposta.status, filme)
import axios from "axios"

try {
  const { data } = await axios.get("http://localhost:5404/filmes/1")
  console.log(data || null)
} catch (error) {
  console.log(error.response.status, error.response.data)
}
  • 200 Filme encontrado. O corpo é o objeto do filme.
  • 200 Filme inexistente. O corpo da resposta fica vazio.
  • 400 Id inválido ou falha na consulta: Erro ao buscar filme
POST

/filmes

Cria um filme. Todos os campos da tabela são obrigatórios, exceto o id. ano e minutos precisam ser números, sem aspas.

curl -X POST http://localhost:5404/filmes \
  -H "Content-Type: application/json" \
  -d '{
    "titulo": "Inception",
    "genero": "Sci-Fi",
    "ano": 2010,
    "minutos": 148,
    "nota": 8.8,
    "sinopse": "Um ladrão invade sonhos para plantar uma ideia.",
    "banner": "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
  }'
const filme = {
  titulo: "Inception",
  genero: "Sci-Fi",
  ano: 2010,
  minutos: 148,
  nota: 8.8,
  sinopse: "Um ladrão invade sonhos para plantar uma ideia.",
  banner: "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
}

const resposta = await fetch("http://localhost:5404/filmes", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(filme)
})

if (!resposta.ok) {
  console.log(resposta.status, await resposta.text())
} else {
  const criado = await resposta.json()
  console.log(criado)
}
import axios from "axios"

const filme = {
  titulo: "Inception",
  genero: "Sci-Fi",
  ano: 2010,
  minutos: 148,
  nota: 8.8,
  sinopse: "Um ladrão invade sonhos para plantar uma ideia.",
  banner: "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
}

try {
  const { data } = await axios.post("http://localhost:5404/filmes", filme)
  console.log(data)
} catch (error) {
  console.log(error.response.status, error.response.data)
}
  • 201 Filme criado, já com o id.
  • 400 Campo ausente ou vazio: Preencha todos os campos
  • 400 titulo com mais de 150 caracteres: Título deve ter no máximo 150 caracteres
  • 400 genero com mais de 50 caracteres: Gênero deve ter no máximo 50 caracteres
  • 400 ano ou minutos enviados como texto: Ano e minutos devem ser números
  • 400 O banco recusou a inserção: Erro ao inserir filme
PUT

/filmes/:id

Substitui todos os dados do filme. O corpo é o mesmo do cadastro. Os sete campos precisam ser enviados de novo.

curl -X PUT http://localhost:5404/filmes/1 \
  -H "Content-Type: application/json" \
  -d '{
    "titulo": "Inception",
    "genero": "Sci-Fi",
    "ano": 2010,
    "minutos": 148,
    "nota": 9.0,
    "sinopse": "Um ladrão invade sonhos para plantar uma ideia.",
    "banner": "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
  }'
const filme = {
  titulo: "Inception",
  genero: "Sci-Fi",
  ano: 2010,
  minutos: 148,
  nota: 9.0,
  sinopse: "Um ladrão invade sonhos para plantar uma ideia.",

const resposta = await fetch("http://localhost:5404/filmes/1", {

if (!resposta.ok) {

import axios from "axios"

  • 200 Filme atualizado. O corpo é o registro depois da alteração.
  • 404 Não existe filme com esse id: Filme não encontrado
  • 400 Mesmas validações do cadastro, ou o banco recusou a atualização: Erro ao atualizar filme
DELETE

/filmes/:id

Remove o filme e devolve o registro que foi apagado.

curl -X DELETE http://localhost:5404/filmes/1
const resposta = await fetch("http://localhost:5404/filmes/1", {
  method: "DELETE"
})

if (!resposta.ok) {
  console.log(resposta.status, await resposta.text())
} else {
  const removido = await resposta.json()
  console.log(removido)
}
import axios from "axios"

try {
  const { data } = await axios.delete("http://localhost:5404/filmes/1")
  console.log(data)
} catch (error) {
  console.log(error.response.status, error.response.data)
}
  • 200 Filme excluído. O corpo é o objeto removido.
  • 404 Não existe filme com esse id: Filme não encontrado
  • 400 O banco recusou a exclusão: Erro ao deletar filme
