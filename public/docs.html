API Filmes

Documentação para cadastrar, listar, consultar, atualizar e excluir filmes. A base da API é http://localhost:5404.

Como executar

  1. Instale as dependências com npm install.
  2. Crie um arquivo .env na raiz do projeto com a connection string do PostgreSQL:
URL_DATABASE=postgresql://usuario:senha@localhost:5432/nome_do_banco

A tabela filmes precisa existir com as colunas id, titulo, genero, ano, minutos, nota, sinopse e banner. O id é gerado pelo banco.

Suba o servidor com npm run dev. Em produção, use npm start. Esta página fica em http://localhost:5404/docs.

Convenções

  • As rotas de filme ficam em /filmes. A documentação continua em /docs.
  • O corpo de POST e PUT deve ser JSON, com o header Content-Type: application/json.
  • Respostas de sucesso são JSON. Mensagens de erro são texto puro.
  • Não há autenticação. O CORS está liberado para qualquer origem.
  • O id vai na URL nas rotas de consulta, atualização e exclusão. Ele não é enviado no corpo.

Campos do filme

Campos aceitos no cadastro e na atualização
Campo Obrigatório Regra
titulo sim texto com no máximo 150 caracteres
genero sim texto com no máximo 50 caracteres
ano sim número
minutos sim número
nota sim valor preenchido
sinopse sim texto
banner sim URL ou texto do pôster
id não gerado pelo banco

ano e minutos com valor 0 são recusados, porque a validação trata 0 como campo vazio.

Exemplo de filme retornado

{
  "id": 1,
  "titulo": "Inception",
  "genero": "Sci-Fi",
  "ano": 2010,
  "minutos": 148,
  "nota": "8.8",
  "sinopse": "Um ladrão invade sonhos para plantar uma ideia.",
  "banner": "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
}

O tipo exato de nota e dos demais campos segue o que o PostgreSQL devolve.

Listar filmes

GET /filmes

Devolve todos os filmes cadastrados.

Requisição

curl http://localhost:5404/filmes

Respostas

200 — lista de filmes. Se não houver registros, a lista vem vazia.

[
  {
    "id": 1,
    "titulo": "Inception",
    "genero": "Sci-Fi",
    "ano": 2010,
    "minutos": 148,
    "nota": "8.8",
    "sinopse": "Um ladrão invade sonhos para plantar uma ideia.",
    "banner": "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
  }
]

400 — falha ao consultar o banco: Erro ao buscar filmes

Buscar filme por id

GET /filmes/:id

Devolve um filme pelo identificador.

Requisição

curl http://localhost:5404/filmes/1

Respostas

200 — filme encontrado. O corpo é o objeto do filme.

200 — filme inexistente. O corpo da resposta fica vazio.

400 — id inválido para o banco ou falha na consulta: Erro ao buscar filme

400 — id ausente na validação: ID não informado

Cadastrar filme

POST /filmes

Cria um filme. Todos os campos da tabela acima são obrigatórios, exceto o id.

Requisição

curl -X POST http://localhost:5404/filmes \
  -H "Content-Type: application/json" \
  -d '{
    "titulo": "Inception",
    "genero": "Sci-Fi",
    "ano": 2010,
    "minutos": 148,
    "nota": 8.8,
    "sinopse": "Um ladrão invade sonhos para plantar uma ideia.",
    "banner": "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
  }'

Respostas

201 — filme criado. O corpo é o registro salvo, já com o id.

400 — algum campo obrigatório não foi enviado ou veio vazio: Preencha todos os campos

400 — titulo com mais de 150 caracteres: Título deve ter no máximo 150 caracteres

400 — genero com mais de 50 caracteres: Gênero deve ter no máximo 50 caracteres

400 — ano ou minutos enviados como texto. No JSON, os dois precisam ser números, sem aspas: Ano e minutos devem ser números

400 — o banco recusou a inserção: Erro ao inserir filme

Atualizar filme

PUT /filmes/:id

Substitui todos os dados do filme. O corpo é o mesmo do cadastro. Não há atualização parcial: os sete campos precisam ser enviados de novo.

Requisição

curl -X PUT http://localhost:5404/filmes/1 \
  -H "Content-Type: application/json" \
  -d '{
    "titulo": "Inception",
    "genero": "Sci-Fi",
    "ano": 2010,
    "minutos": 148,
    "nota": 9.0,
    "sinopse": "Um ladrão invade sonhos para plantar uma ideia.",
    "banner": "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
  }'

Respostas

200 — filme atualizado. O corpo é o registro depois da alteração.

404 — não existe filme com esse id: Filme não encontrado

400 — mesmas validações do cadastro.

400 — id ausente na validação: ID não informado

400 — o banco recusou a atualização: Erro ao atualizar filme

Excluir filme

DELETE /filmes/:id

Remove o filme e devolve o registro que foi apagado.

Requisição

curl -X DELETE http://localhost:5404/filmes/1

Respostas

200 — filme excluído. O corpo é o objeto removido.

404 — não existe filme com esse id: Filme não encontrado

400 — id ausente na validação: ID não informado

400 — o banco recusou a exclusão: Erro ao deletar filme

Exemplo no front-end

const resposta = await fetch("http://localhost:5404/filmes", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    titulo: "Inception",
    genero: "Sci-Fi",
    ano: 2010,
    minutos: 148,
    nota: 8.8,
    sinopse: "Um ladrão invade sonhos para plantar uma ideia.",
    banner: "https://images.unsplash.com/photo-1533488765986-dfa2a9939acd?w=500"
  })
})

const filme = await resposta.json()

Nas rotas de erro o corpo é texto. Use resposta.text() quando o status não for 200 ou 201. Use resposta.json() quando a resposta for um filme ou uma lista.
